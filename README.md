# Monitoring the Analytical Reliability of LLMs with Statistical Process Control

Code, prompts and audit labels for the preprint:

> Bhattacharyya, S. (2026). *Toward a Credible, Accurate and Precise Measurement System for LLM Analytical Errors and Hallucination: Statistical Process Monitoring with CUSUM, EWMA and a Process Reliability Index.* Preprint. [DOI to be added]

Work carried out under the guidance of Dr Subrata Rath, SQC & OR Unit, Indian Statistical Institute, Pune.

## What this study does

Treats an LLM doing statistical analysis as a production process. Each response is audited claim by claim against independently computed reference values and labelled defective or not; labels are grouped into run-level batches and monitored with an upper CUSUM chart on the defect proportion and a lower EWMA chart on a composite LLM Process Reliability Index (LPRI). The pilot covers three Six Sigma datasets analysed by three commercial LLMs in five fresh sessions each (45 planned responses).

This is a pilot. The labels come from a single unblinded, LLM-assisted audit, and chart parameters are illustrative. A blinded two-rater agreement study and a Phase I calibration are specified in the preprint and have not yet been run.

## Reproducing the results

```bash
pip install -r requirements.txt
python analysis/monitoring.py        # batch quantities, LPRI, CUSUM, EWMA, sensitivity analyses, CIs
python analysis/arl_simulation.py    # average run lengths (about a minute)
python analysis/make_figures.py      # Figures 1-3
python analysis/reference_values.py  # reference values, Tables 5-7 and the dated loan reanalysis
```

| Script | Reproduces |
|---|---|
| `monitoring.py` | Tables 9-11 and Section 7.7 |
| `arl_simulation.py` | Table 12 |
| `reference_values.py` | Tables 5-7 and Section 6.4 |
| `make_figures.py` | Figures 1-3 |
| `kappa_analysis.py` | Section 8 agreement statistics (once ratings exist) |
